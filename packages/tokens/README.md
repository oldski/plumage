# @plumage/tokens

Design tokens for Plumage, authored in the W3C DTCG format (2025.10) and built with
[Terrazzo](https://terrazzo.app). One resolver document describes the whole theming
matrix: four brands (Finch, Sparrow, Hummingbird, and Chickadee), two modes, two densities.

## Use it

```css
/* app.css */
@import "tailwindcss";
@import "@plumage/tokens/css";
@import "@plumage/tokens/tailwind.css";
```

```html
<html data-brand="finch" data-theme="dark" data-density="compact"></html>
```

Then style with token utilities only: `bg-surface text-default border-default`,
`h-control-md px-control-md rounded-control`, `text-body`, `gap-sm`, `p-inset-md`.
Tailwind's default palette and scales are switched off, so `bg-zinc-900` or `p-4`
compile to nothing.

From TypeScript:

```ts
import { cssVar, resolve, type TokenName } from "@plumage/tokens";

cssVar("color.chart.categorical.1"); // "var(--pl-color-chart-categorical-1)"
resolve("color.accent.default", { brand: "finch", mode: "dark" }); // "#f4bc00"
```

## Outputs

| Import                          | File                                         | What it is                                                                       |
| ------------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------- |
| `@plumage/tokens/css`           | `dist/plumage.css`                           | CSS custom properties, one rule per layer and context                            |
| `@plumage/tokens/tailwind.css`  | `dist/tailwind.css`                          | Tailwind v4 `@theme inline` mapping                                              |
| `@plumage/tokens`               | `dist/index.js`, `.d.ts`                     | `cssVar`, `resolve`, resolved `values` per permutation, literal token name types |
| `@plumage/tokens/figma/*`       | `dist/figma/<Collection>/<mode>.tokens.json` | Figma variable import files                                                      |
| `@plumage/tokens/manifest.json` | `dist/manifest.json`                         | Per-token metadata for the docs site                                             |
|                                 | `dist/accessibility-report.md`               | Output of `pnpm check`                                                           |

## Source layout

```
src/
  plumage.resolver.json        theming matrix (DTCG Resolver)
  primitives/                  tier 1: raw values, named by value     -> Figma "Primitives"
    color.tokens.json          generated by scripts/generate-ramps.ts
    dimension.tokens.json      space, size, radius, border-width, opacity
    typography.tokens.json     families, weights, sizes, line heights
    effects.tokens.json        shadows, durations, easings
  brands/                      brand palette + brand semantics       -> Figma "Brand"
    finch.tokens.json
    sparrow.tokens.json
    hummingbird.tokens.json
    chickadee.tokens.json
  modes/                       tier 2: colors, chart colors, shadows -> Figma "Mode"
    light.tokens.json
    dark.tokens.json
  density/                     tier 2: spacing, sizes, type sizes    -> Figma "Density"
    compact.tokens.json
    comfortable.tokens.json
  components/                  tier 3: per-component knobs
    components.tokens.json
```

## Scripts

| Command                                                           | Does                                                                             |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `pnpm build`                                                      | Terrazzo build, then Prettier over the CSS                                       |
| `pnpm check`                                                      | Contrast, ramp, chart palette, and tier checks over the build; writes the report |
| `pnpm test`                                                       | Tailwind compile tests, output contract tests, color math tests                  |
| `pnpm ramps`                                                      | Regenerate primitive color ramps from `scripts/ramps.config.ts`                  |
| `node --experimental-strip-types scripts/choose-chart-palette.ts` | Re-derive the categorical chart palette                                          |

## Adding a brand (short version)

1. Copy `src/brands/finch.tokens.json` to `src/brands/<name>.tokens.json`.
2. Point each `brand.color.*` ramp at a primitive ramp, choose the accent `solid` steps
   and `on-solid` text color, and set radius, typefaces, weights, and motion.
3. Add the context to `modifiers.brand.contexts` in `src/plumage.resolver.json`.
4. `pnpm build && pnpm check`. The build fails if your file declares a different set of
   tokens than the others; the check fails if any pairing misses contrast.

The full guide, with the reasoning for each choice, is "Guides/Adding a brand" in Storybook
(`apps/docs/src/adding-a-brand.mdx`).
